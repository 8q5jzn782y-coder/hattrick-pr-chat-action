**Suggested categories:** Code review; Code quality (confirm available categories

## Description

Ask Hattrick about a pull request or a selected section of code. It researches
the engineering question and replies with findings, recommendations, and sources.
Engineers keep control of the final decision and the code changes.

Reports prioritize concerns and keep additional findings expandable. Source labels
link to the references used by each finding. Exact code links identify verified
excerpts; ambiguous excerpts do not receive guessed line numbers. A citation or
code link is not a guarantee that a finding is correct.

The Action is a small MIT-licensed adapter. Hattrick's hosted service performs the
research privately. A Hattrick GitHub App installation and enabled service access
are required. Research allowance and service pricing are separate from the
wrapper's license; do not describe paid research as free use of the Action.

***PILOT***

Code analysis, practical recommendations, and sources—right in your GitHub PR comments.

Invite-only access: **10 requests a day for 14 days from your invitation.**

## Get started

1. Open the magic link in your invitation email.
2. From your [account page](https://www.hattrickai.io/action/account), install the Hattrick GitHub App and select your repositories.
3. Leave a PR comment:

```text
/hattrick review
```

Or ask a question:

```text
/hattrick Could this change lose a queued job during shutdown?
```

You can also comment on selected lines. Hattrick reads the code and replies in GitHub—no copy-paste or workflow setup needed.

Choose your response language in your account settings, or add `[language: Español]` to your comment.
